## Legenda
:
- **CD**: Classe Difficoltà del tiro di crafting
- **Chi**: Axt = Axton | Bel = Bellamy | Alt = Althea | Mel = Melìr | Ere = Erevan | And = Andros | Yan = Yancarlos
- **Fonte ricetta**: Dove trovarla nel mondo di Sherdan
- **Categorie materiali**: ORG = Organico | MIN = Minerale | OBS = Obsidium | TEC = Tecnologico | ARC = Arcano
- **Proprietà**: IGN = Igneo, COR = Corrosivo, CON =Conduttivo, RES = Resistente, VOL = Volatile, RIG = Rigenerante, TOS = Tossico, RIS = Risonante, VIV = Vivente,  STA = Stabile, LUM = Luminoso, OCC = Occulto
- **Tempo**: m = minuti | h = ore | g = giorni | s = settimane

## Regole Rapide
:
### CD e Tempo per Rarità
:
| Rarità | CD base | Tempo base | N° Componenti | Livello necessario |
|:---|:---:|:---:|:---:|:---:|
| Comune | 10-12 | 1h | 2-3 | 1+ |
| Non Comune | 13-15 | 4h | 3-4 | 5+ |
| Raro | 16-18 | 12h | 3-4 | 8+ |
| Molto Raro | 19-22 | 3g | 5-6 (almeno 1 raro) | 12+ |
| Leggendario | 23-25 | 1s | 8 (almeno 2 molto rari) | 18+ |
\column
### Modificatori
:
| Condizione | Modifica alla CD |
|:---|:---:|
| Laboratorio attrezzato | -2 |
| Strumenti improvvisati | +3 |
| Sotto pressione temporale | +3 |
| Assistenza NPC artigiano | Vantaggio al tiro |
:
### Esiti
:
| Risultato | Esito |
|:---|:---|
| CD +5 o più | **Successo Critico** — Oggetto perfetto. Il creatore può dargli un nome. |
| CD a CD +4 | **Successo** — Funziona come da manuale. |
| CD -1 a -4 | **Fallimento Parziale** — La creazione dell'oggetto non è riuscita. Recuperi metà dei componenti (priorità ai meno rari). |
| CD -5 o meno | **Fallimento Totale** — La creazione dell'oggetto non è riuscita. Componenti consumati. |

## Note per il GM
:
### Aggiungere Nuove Ricette
:
Quando voglio inserire un nuovo oggetto ufficiale:

1. Trovo la **rarità** → uso la tabella CD/Tempo
2. Mi chiedo: "Cosa fa questo oggetto?" → scelgo 2-5 proprietà logiche
3. Piazzo la **ricetta** in un luogo coerente col mondo di Sherdan
4. Seguo il formato standard
:

:
{{descriptive
Se un giocatore chiede *"Posso creare [oggetto ufficiale]?"* la risposta è sempre: **"Sì, se trovi la ricetta e i componenti."**
